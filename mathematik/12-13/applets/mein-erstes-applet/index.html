Mein erstes Applet

Hier wird dein vorhandenes Applet direkt auf deiner eigenen Website liegen.

Applet noch nicht eingefügt. Kopiere später die Dateien deines Applets in diesen Ordner. Falls dein Applet bereits eine eigene index.html hat, ersetzt sie diese Platzhalterdatei. Achte dann auf die relativen Dateipfade.
Ein einfaches HTML/CSS/JavaScript-Applet kann direkt hier abgelegt werden. Bei einem React-/Vite-Projekt musst du zuerst den Produktions-Build erstellen und dessen fertige Dateien hochladen. Passe bei Bedarf die Basis-Pfade für die Unterordner-Adresse von GitHub Pages an.
